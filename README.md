# Sistema de Cursos — Microservicios

Empieza por **START_HERE.md**.

La versión anterior del backend monolítico no fue sobrescrita. Este proyecto es una copia nueva donde el dominio fue separado en cinco servicios de negocio independientes, más Eureka y API Gateway.

Documentos clave:
- `START_HERE.md` — preparación y arranque.
- `documentacion/ARQUITECTURA_MICROSERVICIOS.md` — decisiones de arquitectura y seguridad.
- `documentacion/MAPEO_EPICAS_MICROSERVICIOS.md` — épicas por servicio.
- `documentacion/GUIA_DEMOSTRACION_PROFESOR.md` — flujo de exposición y prueba de fallos.
- `VALIDACION_REALIZADA.md` — comprobaciones realizadas al paquete.
